How this RAG application works

Markdown documents are split into overlapping passages of at most 80 words. BM25 ranks passages by query terms. Passages must match at least half of the non-stopword query terms to enter the prompt. This lexical rule is not a semantic relevance guarantee. With no qualifying passage, generation is skipped.

The app sends the question and the highest-ranked passage to a Web Worker running Xenova/flan-t5-small through Transformers.js 3.8.1 and single-threaded WebAssembly. An application limit of 480 input tokens protects the model's context budget. Outputs are displayed as text. First-run downloads and generation speed depend on your connection and device. Browser storage may cache model files. No paid API or authentication is required.

Model errors are shown explicitly; retrieved evidence remains available. The application has no conversation memory, uploads, external tool calls, or shared database. Questions are intended to be in English.
