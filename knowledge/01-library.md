# Library opening hours

The fictional Atlas Learning Lab library opens Monday to Friday from 09:00 to 17:00. It is closed on Saturdays and Sundays. During the demonstration's examination week, the same opening hours apply; there is no evening extension. Visitors enter through the east entrance and may read the printed reference collection inside the library. These hours are invented for this application and do not describe a real university. Questions about library opening hours should use this document as the source.
