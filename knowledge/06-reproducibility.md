# Reproducible builds

For an Atlas demonstration, a reproducible build starts from tracked source files and documented software versions. Run automated checks before deployment. Keep a link to the successful workflow execution as evidence. A workflow configuration file alone does not demonstrate that deployment succeeded. A failed check should prevent publication of the new version. Document external model downloads and first-run requirements so another learner can reproduce the application. These guidelines belong to the fictional Atlas handbook used in this RAG example.
