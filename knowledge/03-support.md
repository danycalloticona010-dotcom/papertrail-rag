# Support desk and reference code

The fictional Atlas Learning Lab support desk uses the reference code ORBIT-42. Include ORBIT-42 when reporting a problem with a demonstration workstation. The support desk is located in Room Cedar, beside the east entrance. A useful support report describes the problem, the workstation number, and the time it occurred. Never include passwords or authentication tokens in a support report. The desk and reference code exist only in this application’s invented handbook and are not real institutional contact details.
