# Demonstration data and privacy

Use only synthetic or explicitly public data in Atlas demonstration projects. Do not upload private student records, passwords, API keys, or confidential documents to a public repository. The example datasets in the handbook are invented and contain no personal records. If a demonstration needs a credential, store it in the hosting provider's secret settings rather than in source code. Before publishing a screenshot or video, review it for notifications, account information, and other unintended disclosures.
